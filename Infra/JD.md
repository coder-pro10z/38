 JD: Job Description

Responsibilities



Azure Infrastructure Architecture & Deployment



Design and deploy Azure landing zones.

Implement subscription design strategy (Prod / Non-Prod segregation).

Configure Management Groups and subscription governance.

Deploy and manage Azure Virtual Machines, VM Scale Sets, Availability Sets & Zones.

Design hub-and-spoke network architecture.

Configure Azure Load Balancer and Application Gateway.

Manage Azure Storage (Blob, File Shares, Managed Disks).

Implement Azure Bastion and Private Endpoints.

Azure Networking & Connectivity



Configure NSGs, Azure Firewall, and User Defined Routes.

Implement Site-to-Site and Point-to-Site VPN.

Configure ExpressRoute connectivity.

Manage Private DNS Zones.

Troubleshoot hybrid connectivity and latency issues.

Azure Identity & Access Governance



Manage Azure RBAC and enforce least privilege access.

Configure Conditional Access Policies and MFA.

Manage Managed Identities and Service Principals.

Security & Compliance



Configure Microsoft Defender for Cloud.

Implement encryption at rest and in transit.

Manage Azure Key Vault for secrets and certificates.

Implement Azure Policy for governance enforcement.

Support Client audits.

Monitoring & Observability



Configure Azure Monitor and Log Analytics.

Create alert rules and dashboards.

Analyze performance metrics and optimize workloads.

Integrate logs with SIEM tools.

Cost Optimization (FinOps)



Monitor Azure cost using Cost Management tools.

Implement budget alerts and tagging policies.

Recommend Reserved Instances and Savings Plans.

Prepare monthly cost optimization reports.

Backup & Disaster Recovery



Configure Azure Backup and Azure Site Recovery.

Design multi-region DR strategy.

Conduct failover and failback testing.

Ensure RPO/RTO compliance.

Experience Requirements



6–8 years total IT experience.

Minimum 3–4 years hands-on Azure production experience.

Experience managing enterprise-scale cloud workloads.

Experience implementing Azure governance frameworks.

Experience in cost optimization and cloud security reviews.

Technical Skills



Expert in Azure IaaS services.

Advanced Azure networking knowledge.

Strong automation and scripting capability.

Experience with Infrastructure-as-Code tools.

Knowledge of Azure security posture management.

Familiarity with DevOps and CI/CD integration.

Preferred Certifications



Microsoft Certified: Azure Administrator Associate.
